# Walix v1.2.5

This file is retained for compatibility with earlier packages. The complete English documentation is available in [README.md](README.md).

## Safe installation

Extract the ZIP archive, enter the extracted directory, and run:

```bash
chmod +x setup.sh
./setup.sh
```

The installer preserves the extracted directory, setup scripts, downloaded archives, and unrelated Kali tools. It only manages files inside `/opt/walix` plus the Walix launcher, desktop entry, and icon it creates.
